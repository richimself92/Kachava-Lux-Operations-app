# CLAUDE.md

## Scope rule (mandatory)

- **Never add features unless the user explicitly asks for them.** Implement exactly what was requested —
  no extra controls, editable fields, settings, options or "while I'm here" improvements.
- If you think something extra would help, **suggest it in your reply and wait** for the user to approve it;
  do not implement it on your own.
- When a request is ambiguous, choose the smallest interpretation that satisfies it, or ask.
